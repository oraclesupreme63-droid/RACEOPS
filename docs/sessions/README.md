# RaceOps — Sessions

Este paquete documenta el módulo que convierte la base operativa en el flujo
central de RaceOps.

## Documentos

- [`session-learning-loop-contract.md`](session-learning-loop-contract.md):
  modelo mínimo, estados, permisos, API y secuencia de implementación.

La documentación distingue la sesión de pista (`Session`) de la sesión de
SQLAlchemy. En código y contratos HTTP, `Session` con mayúscula se refiere a
la actividad de motorsport.
