# RaceOps — Validación de producto

Este directorio conserva únicamente el protocolo, plantillas vacías y
resultados agregados aptos para el repositorio público.

No deben guardarse aquí:

- nombres, correos, teléfonos o equipos identificables;
- audios, fotografías o capturas proporcionadas por participantes;
- configuraciones técnicas, setups o telemetría confidencial;
- credenciales, tokens o archivos exportados sin autorización;
- notas individuales que permitan identificar a una persona.

Los registros privados se almacenan fuera del repositorio en
`docs/validation/private/` o `validation-private/`; ambas rutas están
ignoradas por Git. La ausencia de esos archivos en Git es intencional.

Documentos públicos:

- `validation-protocol.md`: contrato, tareas, métricas y decisiones;
- `scenario-phase-9-v1.md`: dataset completamente sintético e imperfecto;
- `scenario-public-kristianstad-2025.md`: dataset de timing público con
  procedencia y límites de inferencia;
- `public-dataset-findings.md`: métricas reproducidas, hallazgos y decisiones
  obtenidas del timing público;
- `participant-test-guide.md`: preparación y guion neutral del facilitador;
- `templates/consent-template.md`: consentimiento breve para cada sesión;
- `templates/participant-invitation-template.md`: mensaje de invitación;
- `templates/participant-session-template.md`: plantilla privada vacía;
- `templates/task-observation-template.md`: hoja de observación vacía.
