# RaceOps — Protección de registros de investigación

Los registros individuales de las conversaciones de descubrimiento no forman
parte del repositorio público. Se conservan únicamente en el archivo privado
del proyecto porque no existe autorización documentada para publicar su
contenido.

La documentación pública utiliza:

- identificadores anónimos cuando la trazabilidad los requiere;
- conclusiones consolidadas;
- contraevidencia;
- clasificación explícita de incertidumbre;
- ninguna cita textual, nombre, contacto, equipo o configuración técnica.

La ausencia de los registros originales es intencional y no significa que las
conclusiones hayan sido validadas universalmente. RaceOps continúa tratando
una entrevista como señal, no como verdad de mercado.
