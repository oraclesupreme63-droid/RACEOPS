# RaceOps database migrations

Alembic owns every schema change. The database URL is loaded through the
same typed RaceOps settings used by the application; it is not stored in
`alembic.ini`.

Common commands from the repository root:

```powershell
docker compose up -d --wait db
.\.venv\Scripts\python.exe -m alembic current
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m alembic downgrade -1
.\.venv\Scripts\python.exe -m alembic revision --autogenerate -m "description"
```

Every autogenerated migration must be reviewed before it is applied.
The local Docker database is exposed on host port `55432` and persists in the
`raceops_postgres_data` named volume.
